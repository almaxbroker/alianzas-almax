# Alianzas ALMAX Arequipa — web pública

Vitrina de solo lectura con las propiedades que comparten las inmobiliarias de la red Alianzas ALMAX Arequipa.

- Solo datos públicos: fotos, ficha técnica, código de ficha (AL-XXXXX) e inmobiliaria.
- Nunca comisiones, teléfonos ni datos de propietarios.
- Se genera automáticamente desde la plataforma privada (código en el repositorio privado `alianzas-almax-backoffice`). No editar a mano.
